Color Mode: Chrome Extension

I started thinking about what I could do differently. When I read books, the pages are often yellowish, but the colours still look good. I wanted to offer something similar, perhaps a brown or dark sage green colour. So, I created an interactive Chrome extension that allows users to change the colours of websites while browsing. I also realised that if users could change the background colour, then the text colour should change as well, not just black and white. I thought about how to achieve that and came up with a colour-wrapping approach. The user picks a colour using a colour picker, and the text colour is calculated using an offset so that it contrasts with the background.
For example, if I pick light pink, the text becomes darker, and if I pick a dark colour, adding a value such as 80 and wrapping it around the colour range can produce a lighter shade. This way, if the text is dark pink, the background can be light pink, and if the background is light pink, the text can be darker. I think it is a pretty good idea.
